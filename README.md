# Spiker

Landing page for Spiker track spikes. It has a 3D shoe built in code (Three.js) that explodes into its layers and flips to show its pins as you scroll (GSAP + ScrollTrigger), with smooth scrolling (Lenis). The interface is built from [Astryx](https://github.com/meta/astryx), Meta's open-source design system (MIT), rendered with React 19 from jsDelivr; Astryx's stylesheets are inlined with their license notice. It's one static `index.html` with no build step.

Open `index.html` in a browser, or serve the folder with any static host.

Note: model names, weights, pin counts, plate specs and colorway names are placeholders.
